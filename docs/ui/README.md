# HomeTARS UI — Guia Rápido

Referência visual
- "Estética sci-fi minimalista inspirada no TARS de Interstellar: tela preta absoluta (#000000), texto verde neon (#00FF99), tipografia Roboto Mono, layout minimalista sem bordas visíveis e boot sequence."

Regras
- Sem gradientes em conteúdo; usar neon com leve glow (text-shadow suave).
- Layout centralizado vertical/horizontal; responsivo (desktop/tablet/mobile).
- Animações discretas: fade-in, cursor piscante, auto-scroll de logs.
- Paleta: preto, neon verde, verde dim; erro em vermelho moderado.

Componentes atuais
- Terminal: header, área de logs, input com cursor animado.

Evolução
- Phase 2: feedback do backend em tempo real (REST). Phase 3: WebSocket e efeitos.
